# 00-CHelloworld

## Especificaciones Técnicas
- **Compilador seleccionado:** GCC (GNU Compiler Collection)
- **Versión del compilador:** 15.2.0 
- **Estándar de C:** C23
- **Valor de __STDC_VERSION__:** 202311

## Tareas realizadas
- Configuración del entorno en VS Code.
- Creación de `hello_world.c`.
- Compilación manual y mediante `Makefile`.
- Redirección de salida a `output.txt`.

## Instrucciones de ejecución
Para compilar y correr el programa, utilice los comandos definidos en el Makefile:
`mingw32-make run`
